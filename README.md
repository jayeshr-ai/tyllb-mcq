# TY LLB MCQ Trainer

Practice MCQs with explanations for the TY LLB MCQ examination 2026-27:
CPC (jurisdiction and Order V summons), BNSS 2023 (Ss. 1-89), Labour Law II
(Social Security Code 2020, Ss. 59-72) and Public International Law (Units I and II).

Single-file web app: `index.html`. No build step, no server. Progress is saved in the browser.
